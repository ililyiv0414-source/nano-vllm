What changed?

All-zero temperatures are detected from CPU request metadata. Those batches skip temperature preparation and unnecessary random sampling and use compiled argmax. Mixed batches retain the original path.

The fast path changes RNG consumption. Later random requests can differ under the same seed.

What was measured?

A800-SXM4-80GB · Qwen3-0.6B · BF16 · CUDA Graph · 512 input / 64 output tokens · 256 shared prefix tokens.

Generate + GPU synchronization, excluding loading and graph capture. Not TTFT or online P99. Cold/warm observations share workers. No significance claim.

Start with the evidence

The eager pilot did not show end-to-end improvement. CUDA Graph comes from upstream and is enabled in both paths here. These results do not guarantee gains on other hardware or workloads.
